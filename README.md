# Research & Engineering Portfolio

Responsive personal portfolio with research, projects, experience and education.

## Run locally

Open index.html in a browser, or run `python3 -m http.server 8000` from this folder.

## Features

- Responsive desktop and mobile layouts
- Accessible light and dark themes
- Research summaries and project descriptions
- No build step or external dependencies
